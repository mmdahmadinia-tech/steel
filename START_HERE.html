🚀 راهنمای شروع (3 مرحله ساده)

1

بررسی Node.js

فایل debug.bat را اجرا کنید.
اگر Node.js نصب باشد، نسخه آن نمایش داده می‌شود.

2

اجرای run.bat (پیشنهادی)

فایل run.bat را اجرا کنید.
این فایل همه چیز را خودکار انجام می‌دهد:

✓ نصب وابستگی‌ها (بار اول)
✓ ساخت فایل‌های برنامه
✓ اجرای سرور
✓ باز کردن مرورگر

3

ورود به سامانه

مرورگر باز می‌شود. با یکی از کاربران زیر وارد شوید:
نام کاربری: admin
رمز عبور: هر چیزی وارد کنید

📁 فایل‌های BAT موجود

run.bat ⭐ اجرای کامل (پیشنهادی)
debug.bat عیب‌یابی و بررسی
install.bat نصب وابستگی‌ها
build.bat ساخت نسخه نهایی
start.bat سرور توسعه
server.bat سرور ساده

👥 کاربران آزمایشی

رمز عبور: هر چیزی وارد کنید

admin مدیر سامانه
eaf_operator کاربر EAF
lf_operator کاربر LF
ccm_operator کاربر CCM
shift_sup سرپرست شیفت
prod_manager مدیر تولید

❌ اگر هنوز مشکل دارید:

1. فایل debug.bat را اجرا کنید و خروجی را ببینید
2. مطمئن شوید Node.js نصب است (https://nodejs.org)
3. بعد از نصب Node.js، کامپیوتر را ری‌استارت کنید
4. فایل‌ها را از پوشه اصلی پروژه اجرا کنید
5. اگر باز هم کار نکرد، CMD را به عنوان Administrator باز کنید
