🚀 راهنمای شروع (3 مرحله ساده)

1

بررسی نصب Node.js

فایل debug.bat را اجرا کنید تا مطمئن شوید Node.js نصب است.

2

نصب وابستگی‌ها (فقط بار اول)

فایل install.bat را اجرا کنید و صبر کنید تا نصب تمام شود.

3

باز کردن برنامه

فایل open.bat را اجرا کنید. مرورگر خودکار باز می‌شود!

👥 کاربران آزمایشی

رمز عبور: هر چیزی وارد کنید

admin مدیر سامانه
eaf_operator کاربر EAF
lf_operator کاربر LF
ccm_operator کاربر CCM
shift_sup سرپرست شیفت
prod_manager مدیر تولید

⚠️ اگر Node.js نصب نیست:

1. به سایت https://nodejs.org بروید
2. نسخه LTS (20.x) را دانلود کنید
3. نصب کنید و کامپیوتر را ری‌استارت کنید
4. دوباره مراحل بالا را انجام دهید
