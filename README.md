# 🏭 STEELMETRICS - راهنمای نهایی اجرا

## ⚡ فقط 1 فایل: `START.bat`

### این فایل را اجرا کنید:
```
دابل‌کلیک روی START.bat
```

این فایل همه چیز را خودکار انجام می‌دهد:
- ✓ نصب وابستگی‌ها (بار اول)
- ✓ ساخت فایل‌های برنامه
- ✓ اجرای سرور
- ✓ باز کردن مرورگر

---

## 🎯 بعد از اجرا:

1. مرورگر باز می‌شود روی: **http://localhost:3001**
2. با یکی از کاربران زیر وارد شوید:

| نام کاربری | رمز عبور |
|------------|----------|
| admin | هر چیزی |
| eaf_operator | هر چیزی |
| lf_operator | هر چیزی |
| ccm_operator | هر چیزی |
| shift_sup | هر چیزی |
| prod_manager | هر چیزی |

---

## 📁 فایل‌های BAT:

| فایل | کاربرد |
|------|--------|
| **START.bat** ⭐ | اجرای کامل (فقط این را اجرا کنید) |
| debug.bat | عیب‌یابی |
| install.bat | نصب وابستگی‌ها |
| build.bat | ساخت نسخه نهایی |

---

## ❓ مشکل دارید؟

### Node.js نصب نیست:
1. بروید به: https://nodejs.org
2. نسخه LTS (20.x) را دانلود کنید
3. نصب کنید
4. **کامپیوتر را ری‌استارت کنید**
5. دوباره `START.bat` را اجرا کنید

### خطای "Windows cannot find":
- این مشکل حل شده!
- از فایل `START.bat` استفاده کنید

### CMD سریع بسته می‌شود:
- فایل `debug.bat` را اجرا کنید
- خروجی را ببینید
