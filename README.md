# 🏭 STEELMETRICS - راهنمای شروع سریع

## ⚡ شروع در 3 مرحله:

### 1️⃣ فایل START_HERE.html را باز کنید
- این فایل راهنمای تصویری است
- همه چیز را توضیح می‌دهد

### 2️⃣ فایل open.bat را اجرا کنید
- دابل‌کلیک کنید
- مرورگر خودکار باز می‌شود
- تمام!

### 3️⃣ وارد شوید
```
نام کاربری: admin
رمز عبور:   admin
```

---

## 📁 فایل‌های BAT:

| فایل | کاربرد |
|------|--------|
| **START_HERE.html** | 📖 راهنمای تصویری (اول این را ببینید) |
| **debug.bat** | 🔍 عیب‌یابی و بررسی نصب |
| **install.bat** | 📦 نصب وابستگی‌ها (بار اول) |
| **open.bat** | 🚀 باز کردن سریع برنامه |
| **start.bat** | 🖥️ اجرای سرور توسعه |
| **build.bat** | 🏗️ ساخت نسخه نهایی |

## ❓ مشکل دارید؟

### Node.js نصب نیست:
1. بروید به: https://nodejs.org
2. نسخه LTS (20.x) را دانلود کنید
3. نصب کنید
4. **کامپیوتر را ری‌استارت کنید**
5. دوباره تلاش کنید

### CMD سریع بسته می‌شود:
- فایل `debug.bat` را اجرا کنید
- خروجی را ببینید
- مشکل را پیدا کنید

### خطای npm:
```cmd
npm cache clean --force
rmdir /s /q node_modules
npm install
```
